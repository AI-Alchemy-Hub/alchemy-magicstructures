# Glossary – Alchemy MagicStructures

- **Magic Prefix**: Naming convention for all classes (MagicArray, MagicStack).
- **Expand/Shrink**: Dynamic capacity adjustment of structures.
- **Overflow/Underflow**: Error conditions when exceeding or reducing capacity.
- **Benchmarking**: Complexity metadata and runtime comparisons.
- **Visualization Hook**: Method to display and save/export structures.
