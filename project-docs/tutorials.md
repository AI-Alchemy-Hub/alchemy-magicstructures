# Tutorials – Alchemy MagicStructures

## Purpose  
This document outlines the tutorial philosophy and structure for each Magic*** class. Tutorials are designed to provide learners with **hands‑on practice**, **conceptual clarity**, and **progressive mastery** of data structures and algorithms.

## Tutorial Principles
- **Completeness:** Each tutorial must cover all operations and algorithms relevant to the class.  
- **Universality:** Tutorials must demonstrate diverse data types (integers, strings, sets, lists, objects).  
- **Visualization:** Tutorials must include visualization hooks where applicable.  
- **Benchmarking:** Tutorials must show complexity comparisons between algorithms.  
- **Error Pedagogy:** Tutorials must simulate overflow, underflow, collisions, and other pitfalls.  
- **Gamification:** Tutorials should include challenges and badges to motivate learners.  

## Tutorial Structure
Each tutorial will follow a consistent format:
1. **Introduction:** Brief overview of the data structure.  
2. **Setup:** Instructions to initialize the Magic class.  
3. **Core Operations:** Step‑by‑step examples of all valid operations.  
4. **Visualization:** Demonstration of display and save/export features.  
5. **Benchmarking:** Comparison of algorithm complexities with runtime examples.  
6. **Error Simulation:** Examples of overflow, underflow, or collisions.  
7. **Challenges:** Practice tasks with guided hints.  
8. **Reflection:** Key takeaways and links to related Magic classes.  

## Tutorials by Class

### MagicArray
- Arrays of integers, strings, sets, objects.  
- Sorting algorithms (Bubble, Shell, Quick) with complexity benchmarking.  
- Expand/shrink capacity demonstration.  
- Visualization of array slices.  

### MagicMatrix2D & MagicMatrix3D
- Determinant, transpose, multiplication, inversion.  
- Visualization of 2D and 3D matrices.  
- Benchmarking matrix operations.  
- Tutorials: school‑level 2D examples, university‑level 3D manipulations.  

### MagicLinkedList
- Singly and doubly linked lists.  
- Insertions, deletions, traversals, reverse, search.  
- Visualization of node connections.  
- Error simulation: null pointer references.  

### MagicStack
- Push, pop, peek, isEmpty, isFull, getSize.  
- Benchmarking stack operations.  
- Tutorials: stack of strings, stack of files.  
- Error simulation: stack overflow/underflow.  

### MagicQueue
- Enqueue, dequeue, peekFront, peekRear, isEmpty, isFull.  
- Circular queue variant.  
- Tutorials: queue of tasks, queue of objects.  
- Error simulation: queue overflow/underflow.  

### MagicHashMap
- Insert, delete, search, collision handling.  
- Benchmarking hash functions.  
- Tutorials: hashmap of student records, hashmap of sets.  
- Error simulation: collision resolution.  

### MagicTree
- Binary tree traversals (inorder, preorder, postorder, level order).  
- Insert, delete, search, height, balance checks.  
- Visualization hook: `displayAndSave("TreeIMG.png")`.  
- Tutorials: binary tree of lists, binary tree of animals.  

### MagicGraph
- Graph with adjacency list/matrix.  
- BFS, DFS, shortest path, connectivity checks.  
- Visualization with NetworkX/Matplotlib.  
- Tutorials: graph of cities, graph of social networks.
