# Style Guide – Alchemy MagicStructures

## Naming
- Classes: Prefix with **Magic*** (e.g., MagicArray).
- Methods: Use camelCase (e.g., push(), displayAndSave()).

## Formatting
- Follow PEP 8 for Python code.
- Use docstrings for all classes and methods.
- Inline comments for complex logic.

## Documentation
- Markdown files in `/docs/`.
- Tutorials must follow [tutorials.md](tutorials.md) structure.
