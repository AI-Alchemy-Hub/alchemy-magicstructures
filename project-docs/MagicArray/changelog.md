# MagicArray Changelog

## v0.2.0 (Milestone 1 – MagicArray)
- Implemented MagicArray class.
- Added constructors for empty, pre‑filled, max size, external source.
- Implemented insert, delete, update, search.
- Added sorting algorithms (bubble, insertion, selection, merge, quick).
- Integrated expand/shrink capacity.
- Added visualization and export methods.
- Introduced benchmarking hooks.
- Completed tutorials and tests.
