# MagicArray Tutorials

Learn how to use MagicArray for classroom teaching, fun experiments, and professional projects.

- Create empty, pre‑filled, and max‑size arrays.

- Insert, delete, update, search.
- Practice with sample datasets.

### Tutorial 3 – Sorting Algorithms
- Compare bubble, insertion, selection, merge, quick.
- Benchmark runtime differences.

### Tutorial 4 – Expand/Shrink
- Demonstrate dynamic capacity.
- Simulate overflow/underflow.

### Tutorial 5 – Visualization
- Display array contents.
- Save/export to PNG, JSON, CSV.

### Tutorial 6 – Error Simulation
- Trigger invalid index access.
- Handle gracefully with error messages.
