# Contributing Guidelines – Alchemy MagicStructures

We welcome contributions from the community. Please follow these guidelines:

## Code Standards
- Prefix all classes with **Magic***.
- Follow [styleguide.md](styleguide.md) for naming and formatting.
- Include docstrings for all methods.

## Pull Requests
- Fork the repository.
- Create a feature branch.
- Write unit tests for new features.
- Submit a pull request with a clear description.

## Documentation
- Update relevant `.md` files in `/docs/`.
- Add tutorials for new classes or features.

## Community
- Respectful communication.
- Collaborative spirit aligned with AI AlchemyHub ethos.
